# QR Code de acesso: Expo Go

![QR Code do app no Expo Go](QR-CODE-EXPO-GO.png)

## Como abrir

1. Instale o **Expo Go** (App Store / Google Play), sempre atualizado.
2. Entre no Expo Go com a sua conta Expo, que precisa ser **membro da organização `flamengo-app`** em expo.dev.
3. Escaneie o QR acima: no iPhone, com a **câmera**; no Android, pelo **Expo Go**.

O QR é **fixo**: sempre abre a última versão publicada. Quem já abriu recebe a versão nova ao fechar e reabrir o app.

Link equivalente, para mandar por mensagem:

```
exp://u.expo.dev/fc684d85-dbe4-483e-8330-44e088324fd7?channel-name=demo&runtime-version=exposdk%3A58.0.0
```

## Publicar uma versão nova

Depois de mudar o código, rode na pasta do projeto: `npm run publicar`. Os detalhes estão em [docs/PUBLICAR.md](../docs/PUBLICAR.md).
