# Card do próximo jogo: cinco layouts (estudo)

**Escolhido: o 5 (cartão com margem)**, mais enxuto: sem rodada e estádio, e no alto só "Hoje",
"Amanhã" ou a data curta com a hora. Já é o card oficial: `oficial-*.png` (dia de jogo, pré-jogo,
ao vivo, pós-jogo e tema claro). O código das variantes saiu do app; os prints ficam como registro.

Mesmas fontes, escudos, contagem e botões; só muda a disposição. Prints no cenário "dia de jogo", tema escuro.

| Print | Ideia |
| --- | --- |
| `0-atual.png` | Card de hoje (já com o topo novo da Home). |
| `1-lista-de-jogo.png` | Os dois times em linhas, alinhados à esquerda, com a hora grande à direita; contagem embaixo. |
| `2-tipografico.png` | Bloco vermelho liso, sem foto: "Flamengo × Palmeiras" em duas linhas, escudos empilhados, monograma de fundo. |
| `3-foto-e-painel.png` | Confronto sobre a foto; embaixo, um painel liso com hora, contagem e botões. |
| `4-contagem-primeiro.png` | O tempo que falta é o protagonista; o confronto vira uma linha no alto. |
| `5-cartao-com-margem.png` | O card recolhido, com cantos arredondados e respiro dos lados; escudos grandes no centro. |

`comparacao.png`: as seis lado a lado (atual, 1, 2 / 3, 4, 5).
