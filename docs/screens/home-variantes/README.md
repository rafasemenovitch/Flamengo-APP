Já é a Home oficial: `oficial-escuro.png` e `oficial-claro.png`. O código das variantes saiu do app;
os prints abaixo ficam como registro.


| Print | O que muda |
| --- | --- |
| `0-atual.png` | Home de hoje, para comparar. |
| `1-nivel-no-canto.png` | Nível, pontos e barra da trilha sobem para o espaço vazio à direita do nome. Embaixo dos atalhos fica só o próximo prêmio. |
| `2-assistente-no-topo.png` | O assistente sai do botão flutuante e vira um botão fixo ao lado do nome. A faixa de nível fica onde está. |
| `3-anel-de-nivel.png` | Nível como anel de progresso com o número dentro, ao lado do nome. |
| `4-topo-compacto.png` | Saudação numa linha com o nível e os pontos numa pílula; o jogo sobe; o assistente vira o 5º atalho (sem botão flutuante). |
| `5-trilha-como-fio.png` | Pontos grandes à direita do nome e a barra da trilha de ponta a ponta logo abaixo, com nível atual e próximo nas pontas. |
