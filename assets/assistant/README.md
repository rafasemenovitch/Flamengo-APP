# Assistente Fla (skin "modo assistente")

Poses do Urubu com headset, usadas SOMENTE no chat do Assistente Fla (e no botão que o abre).
Não são as imagens oficiais do mascote torcedor.

- `*.png`: as 16 poses (expressões 01–08 em 384px; gestos 09–16 em 480px).
- `avatar/*.png`: expressões 01–08 recortadas do headset à gola (192px) para avatares pequenos.

Origem: pasta `Imagens Assistente Fla/assistente-fla 2/` (manifest.json com quando usar cada pose).
Mapa pose → arquivo: `src/features/assistant/poses.ts`.
